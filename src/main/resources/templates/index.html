Project Modules

Overview of the core functional components to be implemented in subsequent project phases.

1. Authentication & RBAC Active • Implemented

Role-based access control for Students, Mess Managers, and System Administrators with secure session management.

2. Student & Mess Profile Planned

Student hostel room allotment, active mess membership, and dietary preference records.

3. Meal Exemption Requests Planned

Automated submission of advance leave/meal opt-out applications with rule-based cutoff validation.

4. Daily Attendance Tracking Planned

Daily breakfast, lunch, and dinner attendance logging with instant cross-verification against approved exemptions.

5. Rebate Calculation Engine Planned

Automated computation of meal rebates based on institutional policy (minimum consecutive days and approved leaves).

6. Monthly Billing & Invoices Planned

Monthly mess invoice generation deducting computed rebates from the base mess fee, with detailed bill breakdown.

Standard MVC Layered Architecture

The application follows a clean 4-tier architectural pattern suited for academic evaluation, ensuring separation of concerns:

Layer Package Responsibility
Presentation (View) templates/ Thymeleaf templates rendering clean HTML5 with Bootstrap styling.
Web Controller com.hostel.mess.controller Handles incoming HTTP GET/POST requests, populates models, and routes to views.
Business Service com.hostel.mess.service Implements business logic (rebate rules, exemption limits, billing algorithms).
Data Access (Repository) com.hostel.mess.repository Spring Data JPA interfaces executing database operations without boilerplate SQL.
Domain Model (Entity) com.hostel.mess.entity JPA / Hibernate entities mapping relational PostgreSQL tables to Java objects.
